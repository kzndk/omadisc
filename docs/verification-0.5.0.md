# OmaDisc 0.5.0 — All channels menu

The top toolbar now contains an **All channels** dropdown built from every saved pane assignment. Entries use the pane number and its saved label, falling back to Discord's page title or channel identifier. Selecting an entry focuses that channel without changing the saved 1/2/4/6-pane layout, so hidden channels remain directly accessible and **Back to grid** restores the prior view.

Verification covers all six labelled entries, selection of pane six while the one-pane layout is active, restoration of that one-pane grid, retained drafts, and the existing independent pane and security behavior. The unit suite, source Electron integration suite, packaged Electron integration suite, syntax check and local installation check passed under the repository's resource-limited wrappers.

The running 0.4.1 process was left untouched. The 0.5.0 release was installed side-by-side and becomes active after OmaDisc is closed and reopened.
